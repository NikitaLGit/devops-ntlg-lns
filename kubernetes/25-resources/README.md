## Задание

Минимальные ресурсы необходимые для разворачивания нод кластера:

||CPU|RAM|HDD|
|---|---|---|---|
|Control Node|2 ядра|2 ГБ|50 ГБ|
|Worker Node|1 ядр|1 ГБ|100 ГБ|
|||||

Ресурсы для проекта:

| Компонент   | Тип ресурса | Реплики | CPU (на копию) | RAM (на копию) | Общий CPU  | Общая RAM         |
| ----------- | ----------- | ------- | -------------- | -------------- | ---------- | ----------------- |
| База данных | StatefulSet | 3       | 1              | 4 ГБ           | 3          | 12 ГБ             |
| Кеш         | StatefulSet | 3       | 1              | 4 ГБ           | 3          | 12 ГБ             |
| Backend     | Deployment  | 10      | 1              | 600 МБ         | 10         | 6 ГБ             |
| Frontend    | Deployment  | 5       | 0.2            | 50 МБ          | 1          | 250 МБ           |
| **ИТОГО**   | —           | —       | —              | —              | **17 CPU** | **30.25 ГБ RAM** |
|  |  |  |  |  |  |  |

С учётом минимального запаса (+40%):

`CPU`:
* минимум: 17
* рекомендуется: 24 CPU

`RAM`:
* минимум: 30.25 ГБ
* рекомендуется: ~43 ГБ RAM

Теперь разобьем на 3 ноды

`CPU`: 24 / 3 = 8 + 1 (на работу ноды) = 9
`RAM`: 43 / 3 = 15 + 1 (на работу ноды) = 16

## Итого

Нужно 3 `Worker Node`. Характеристики одной ноды `9 CPU`, `16 RAM`;

Нужно 3 `Control Node`. Характеристики одной ноды `2 CPU`, `2 RAM`.
